# Оркестрация ETL, отчётов и алертов в Apache Airflow

Репозиторий с проектами по оркестрации данных, автоматизации отчётности и мониторингу аномалий с помощью Apache Airflow.

## Проекты

### 1. Автоматический отчёт по ленте новостей
DAG для ежедневной отправки аналитической сводки по ленте в Telegram. Включает текстовый отчёт с метриками за предыдущий день и график динамики за 7 дней.

[Подробнее о проекте](./feed_report_task/README.md)

### 2. Комплексный отчёт по работе приложения
DAG для отчёта по всему приложению (лента + мессенджер). Содержит детальную текстовую сводку с отклонениями и 5 графиков.

[Подробнее о проекте](./app_report_task/README.md)

### 3. Система алертов для мониторинга аномалий
DAG для проверки ключевых метрик каждые 15 минут. Использует ансамбль статистических методов (diff, IQR, 3-sigma) для детектирования аномалий и отправляет алерт с графиком в Telegram.

[Подробнее о проекте](./alert_system/README.md)

## Общий стек технологий
Во всех проектах используется:
*   **Оркестрация:** Apache Airflow
*   **База данных:** ClickHouse
*   **Работа с данными:** Pandas
*   **Визуализация:** Seaborn, Matplotlib
*   **Интеграции:** Telegram Bot API
